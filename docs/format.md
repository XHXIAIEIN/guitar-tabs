# 曲谱格式与保存

吉他曲谱本通过 alphaTab 转换外部文件，并使用单轨、单声部的六弦曲谱模型进行编辑和播放。

## 导入与导出

| 格式 | 文件扩展名 | 范围 |
| --- | --- | --- |
| alphaTex | `.atex` | 解析与导出受支持的曲谱内容 |
| 普通 MusicXML | `.xml`、`.musicxml` | 每个有音高的音符必须包含弦号和品位 |
| Guitar Pro | `.gp`、`.gp3`、`.gp4`、`.gp5`、`.gpx`、`.gp7` | 由 alphaTab 读取，再检查是否符合内部模型 |

导出使用 alphaTex。曲库备份使用 JSON，包含保存条目的标识、曲谱内容和保存时间；它与单首曲谱导出用途不同。

普通 MusicXML 和 Guitar Pro 7 样例已有导入检查。其他 Guitar Pro 版本的扩展名可被接受，但兼容性取决于文件内容和解析器支持。压缩 MusicXML `.mxl` 不在导入入口范围内。

## 音乐内容

内部时间使用整数刻度，每四分音符为 960 刻度。弦号从上到下为 1–6，调弦数组使用相同顺序。转换时会反转 alphaTab 的内部弦号。每个拍组包含起点、时值、附点数和同时发声的音符；空音符数组表示休止。

支持品位 0–36、全音符至六十四分音符、最多两个附点、同拍多弦和延音。编辑工具提供全音符至十六分音符。拍号、调号和速度可以在小节起点改变。延音需要紧邻的同弦同品音符。小节可以未填满，但不能超出拍号规定的时值。

转换器检查轨道、声部、六弦位置及技法。多轨、多声部、变调夹、三连音、弯音、滑音、歌词和其他模型未支持的内容会触发错误，当前曲谱保留。往返检查比较音乐内容，忽略内部标识和文本排版。

alphaTex 使用 `品位.弦号.时值`。例如 `3.2.4` 表示第 2 弦第 3 品的四分音符。示例源谱见[入门曲谱](../scores/beginner/README.md)。

## 布局与播放

播放使用内置的 FreePats 古典吉他录音。采样采用单声道 PCM WAV，随生产站点缓存。相邻音高由最近的采样移调，音符保留录音的自然衰减；定位到延音中间时从对应的采样位置继续。采样来源和 CC0 授权见[音源说明](../src/assets/audio/guitar/README.md)。

首次播放会载入音色，按钮显示载入状态，再次点按可以取消。音源失败后可点击重试。音频在播放按钮的点击中启动；切到后台或音频被系统打断时保留位置并暂停，返回后点击播放继续。支持 Audio Session API 的浏览器使用 `playback` 类型；其他浏览器仍通过 Web Audio 播放。

谱面顶部的 BPM 输入框可以在阅读、编辑和播放时修改速度。有效输入立即生效，并随曲谱保存；撤销和导出也包含速度。各小节的速度按比例调整，并保持在 20–300 BPM 范围内。播放中的 BPM 与倍速调整保留当前拍点，暂停时调整速度会保留暂停状态。

播放时，浅色拍位底纹位于谱线后方，当前和弦中的品位同时高亮。暂停保留拍位，停止清除高亮。进度条可以在首次播放前定位。当前行会随播放换行，横向溢出的拍位会滚入视野。手动滚动时暂停跟随，谱面右下角显示独立的“回到播放位置”胶囊按钮；点击按钮返回当前拍位并继续跟随。点击播放或拖动进度条也会恢复跟随。

每行按拍号分子累计拍数，保持小节完整。拍数设置提供 4、8、12 和 16，默认使用 8。一行内按音乐时间定位拍点，小节连接处增加留白。各行弦线对齐，小节线位置按拍号和音符密度计算；末行不足时从左侧开始。

窄屏根据音符密度缩小数字。数字仍放不下时，整行可以横向滚动。编辑网格支持四分、八分和十六分拍点；较细网格也会为点选预留空间。

曲谱 Worker 负责解析、导入、导出和布局。任务携带请求号及曲谱版本，迟到结果不能覆盖当前曲谱。编辑会重新计算受影响的整行，长谱只绘制可见区域附近的小节。播放 Worker 生成时间表，音频按 AudioContext 时钟提前调度。

## 语言与保存

界面、校验和操作错误文案集中在 `src/i18n/`。中文浏览器首次使用中文，其他浏览器语言使用英文。保存的语言偏好优先于浏览器语言。内置歌曲的已知标题可翻译，自定义标题、目录名和用户输入保持原文。

浏览器曲库使用 localStorage，源谱条目标识来自相对路径。移动源文件会生成不同标识；原有保存条目仍可作为浏览器中的曲谱打开。备份前应确认要保留的编辑结果。

每次写入前会保留上一份可读曲库。主记录损坏时尝试读取恢复副本。保存失败时保留当前编辑并提供重试或导出。恢复整体备份先校验全部条目，再替换已保存曲库。显示偏好单独保存，不包含在曲库备份中。

使用入口见[中文 README](../README.zh-CN.md)，检查方法见[验证说明](validation.md)。
