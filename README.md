# 六弦本

六弦本是给吉他初学者用的练习和演出工具。练习时，在电脑或手机上看六线谱和简谱，跟着节拍器和示范音弹。出门弹唱时，用演出模式看大字和弦和歌词。它是纯前端网页应用，可以添加到手机主屏幕，离线使用。

## 功能

- 曲谱：和弦、简谱、扫弦箭头、音符、六线谱和歌词上下对齐。六线谱、和弦、歌词可以在「显示」里单独开关。「简谱」一组有两个开关，默认都关闭：数字，以及音符（一排带符头的节奏符号，在六线谱上方）。扫弦箭头跟着六线谱显示。
- 弦线与标签：六线谱左右两侧各选一种标签：弦号（123456）、音名（EBGDAe）、TAB 或不显示，默认左侧显示弦号。弦线可以选统一细线或仿真粗细。
- 版本：内置曲谱默认打开简单版。歌曲的简单版只有 1、2 弦上的旋律和歌词。练习的简单版速度更慢，爬格子和音阶只用 1、2 弦，扫弦和分解和弦只用 Em、Am。有完整版的曲谱可以在「练习设置」里切换。每个版本有自己的速度、变调夹和循环。
- 排版：一行放一个完整乐句。同一段里每行小节数相同，只有最后一行可以更短。
- 播放：预备拍、节拍器、示范音和当前音符高亮。示范音用古典吉他的真实录音。速度可以调，也可以点击测速。
- 跟随：播放时页面跟着当前小节滚动。手动滚动后页面停在原处，点「回到播放位置」重新跟随。
- 小节循环：选一段小节反复练。可以设成每循环一次自动加快几 BPM，到设定的最高速度为止。
- 变调夹与移调：调号和示范音跟着变调夹变。只有和弦的曲谱可以换指法调。选好「想唱的调」后，会列出难和弦最少的几种夹法。难和弦指横按或要按到 3 品以上的和弦。
- 演出模式：大字和弦加歌词，深色舞台配色，屏幕常亮，有翻屏按钮。可以按演出歌单一首接一首弹。
- 和弦库：指法图标出手指编号和根音。点一个和弦可以听声音、看其他按法。
- 换和弦练习：当前和弦最大，下一个和弦显示在旁边或下方，最后一拍提示换和弦。手机上，和弦组合、拍数和速度放在底部面板里。
- 一分钟挑战：数一分钟内能来回换几次和弦，每点一次 +1 弹出 Perfect，每组和弦保存最近的成绩。
- 节奏：细分有四分、八分、三连音、十六分，另有常用扫弦节奏型。点格子可以修改，下方自动生成节奏谱：五线谱上的斜线符头，切音画成 ×，上方标扫弦方向。歌曲开头的节奏型也用这种谱。
- 跟拍测试：跟着节拍器点击，显示每一下偏早还是偏晚。可以先校准设备的点击延迟。
- 工具：节拍器、调音器（用麦克风）、六根空弦的标准音。
- 写曲谱：用下面的文本格式写，边写边预览，错误提示带行号。

## 在电脑上运行

在项目目录运行（需要 Python 3）：

```bash
python -m http.server 5173
```

然后用浏览器打开 http://localhost:5173 。直接双击 `index.html` 打不开，因为浏览器不允许从 `file://` 加载 ES 模块。

## 在手机上使用

离线缓存、调音器和屏幕常亮只在 HTTPS 页面或 localhost 上可用，所以手机要通过 HTTPS 网站打开。用 GitHub Pages 发布：

1. 把仓库推送到 GitHub。
2. 打开仓库的 Settings → Pages。
3. Source 选 Deploy from a branch。
4. 分支选 `main`，目录选 `/ (root)`，保存。
5. 部署完成后，用手机打开 `https://<用户名>.github.io/<仓库名>/`。
6. 添加到主屏幕：
   - iPhone：在 Safari 里点「分享」，再点「添加到主屏幕」。
   - Android：在 Chrome 菜单里点「添加到主屏幕」或「安装应用」。

打开过一次以后，没有网络也能用。有网络时，页面先取最新版本。网络超过 2.5 秒没响应时，页面用缓存。

在家里临时试用时，也可以用局域网：

1. 让手机和电脑连同一个 Wi-Fi。
2. 在电脑上运行 `python -m http.server 5173 --bind 0.0.0.0`。
3. 在手机上打开 `http://<电脑的局域网 IP>:5173`。

这种方式是 HTTP，离线缓存、调音器和屏幕常亮都不可用。

## 数据保存

自己的曲谱、设置、工具页的选择、演出歌单和练习记录保存在当前浏览器的 localStorage 里。清除浏览器数据会删掉它们，换设备或换浏览器也看不到。

曲谱页的「导出备份」把曲谱、演出歌单和练习记录存成一个 JSON 文件。在另一台设备上，用「导入备份」恢复这个文件。设置、工具页的选择、选中的版本和每首曲谱的速度、变调夹、循环不在备份里。

## 曲谱写法

编辑器右上角的「写法说明」是这一节的简版。一个例子：

```text
title: 小星星
key: C
bpm: 90
time: 4/4

# 第一段
chord: | C | C | F C | G C |
tab:   | q 5/3 5/3 3/0 3/0 | 3/2 3/2 h 3/0 | q 4/3 4/3 4/2 4/2 | 4/0 4/0 h 5/3 |
lyric: | 一闪一闪 | 亮晶晶 | 满天都是 | 小星星 |

# 弹唱
chord: | C . Am . | F G |
lyric: | 只写和弦和歌词也可以 | 歌词整段显示在小节下面 |
```

开头的 `名称: 值` 行是曲谱信息：

| 写法 | 中文写法 | 含义 |
|------|----------|------|
| `title` | 标题、歌名 | 曲名 |
| `artist` | 作者、演唱、词曲 | 作者 |
| `key` | 调 | 调，如 `C`、`G`、`Eb`、`Am` |
| `capo` | 变调夹 | 变调夹品位 |
| `bpm`、`tempo` | 速度 | 每分钟拍数 |
| `time` | 拍号 | `4/4`、`3/4`、`6/8` |
| `strum` | 节奏型 | 弹唱的扫弦节奏，写法同六线谱，如 `q D e D U r U D U` |
| `pickup` | 弱起 | 弱起小节的拍数，只有和弦时才需要写。有六线谱时，第一小节写短了会自动当作弱起 |
| `octave` | 简谱八度 | 简谱的八度，默认自动选。`1` 整体高一个八度显示，`-1` 低一个八度 |
| `level` | 难度 | 难度标签 |
| `note` | 说明 | 练习说明。`{T}`、`{1}` 到 `{4}` 显示成彩色手指标记（T 拇指，1 食指，2 中指，3 无名指，4 小指），有标记时说明上方显示图例 |

之后的内容：

- `# 名称` 开始一个段落。
- `chord:`、`tab:`、`lyric:` 三行连在一起是一组，空行分开不同的组。三种行也可以写成 `和弦:`、`六线谱:`、`歌词:`。
- `|` 分隔小节。同一组里第几个格子，就属于第几个小节。
- 和弦格：一个和弦占整小节，`C G` 平分小节。`C . Am .` 里每个记号占一拍，`.` 表示延续前一个和弦。
- 歌词格：六线谱有音符时，歌词按顺序对到音符上。汉字一字一音，英文按空格和 `-` 分，`_` 表示这个音延续上一个字。没有音符时，歌词整段显示在小节下面。
- `//` 开头的行是注释。

六线谱格里的记号：

| 记号 | 含义 |
|------|------|
| `w h q e s` | 全音符、二分、四分、八分、十六分音符。写一次后一直有效，直到写下一个时值 |
| `q.` `e.` | 附点，时值乘 1.5 |
| `e3` | 三连音，3 个 `e3` 占一拍 |
| `5/3` | 5 弦 3 品，1 弦是最细的弦 |
| `5/3+2/1` | 同时弹的几个音 |
| `4/x` | 闷音 |
| `r` | 休止 |
| `D` `U` `X` | 下扫、上扫、切音，扫的是当前和弦；也可以写 `下`、`上`、`切` |

除了弱起小节，每小节的时值必须正好等于拍号规定的长度。不对时，编辑器会指出是哪一行。

## 开发

根目录只放入口文件和分类目录：

- `index.html`、`manifest.webmanifest`、`sw.js`：这三个文件必须在站点根目录，因为 GitHub Pages 从根目录发布，service worker 只能控制它所在目录以下的页面。
- `config/app.json`：可调的常量和默认值，例如速度范围、默认设置、预设节奏型、和弦分组和录音列表。
- `lang/`：界面文案，每种语言一个文件。
- `scores/`：内置曲谱，见下面的「增加内置曲谱」。
- `assets/icons/`：应用图标。
- `assets/audio/guitar/`：示范音用的古典吉他录音，来自 FreePats，CC0 许可。来源见目录里的 `README.md`。
- `src/`：源代码，见下面的列表。
- `tests/`：`node --test` 测试。
- `scripts/`：生成图标的脚本。

`src/` 下的目录：

- `app/`：启动顺序、路由和页面外框。
- `core/`：读取配置、多语言和 localStorage 读写，不依赖其他模块。
- `state/`：保存的状态、数据迁移、曲谱条目、演出歌单、每首曲谱的偏好和备份。
- `music/`：乐理（音名、调、简谱）和和弦指法。`music/format/` 解析曲谱文本。
- `render/`：曲谱和和弦图的 SVG 渲染。
- `audio/`：Web Audio 吉他采样播放、节拍器音色、按拍调度和音高检测。
- `ui/`：通用界面组件。
- `views/`：各个页面，一个页面一个目录。
- `styles/`：样式，按组件分文件。`app.css` 的 `@import` 顺序就是层叠顺序。

`config`、界面文案和内置曲谱在启动时才载入，所以模块加载时不能调用 `t()`，也不能读 `config` 或 `BUILTIN`，只能在函数运行时用。数据里存 id，渲染时再翻译。

运行测试（需要 Node.js 22 或更新版本）：

```bash
npm test
```

测试检查这些内容：

- 和弦指法里的音都属于该和弦，内置曲谱解析没有错误，旋律和写好的简谱一致。
- 旧格式的保存数据能迁移，缺的字段由默认值补上，备份能导出再导入。
- 代码用到的文案键都存在，语言文件没有多余的键，文案以外的代码没有中文。
- `sw.js` 的离线列表和实际文件一致，录音列表和配置一致。
- `scores/index.json` 和 `scores/` 下的文件一一对应。

### 增加内置曲谱

每首曲谱有自己的文件夹 `scores/<group>/<id>/`。`group` 是 `exercise` 或 `song`。

1. 写曲谱文件。只有一个版本时，文件是 `<id>.txt`。有多个版本时，每个版本一个文件，如 `simple.txt` 和 `full.txt`。
2. 在 `scores/index.json` 里登记。条目的顺序就是曲谱列表的顺序。多个版本写在 `versions` 里，第一个是默认版本。
3. 把新文件加进 `sw.js` 的 `SHELL` 列表。

### 增加一种语言

1. 把 `lang/zh_CN.json` 复制成新文件并翻译。缺的键显示默认语言的文案。
2. 在 `config/app.json` 的 `i18n.locales` 里登记语言代码、文件名和显示名。
3. 把新文件加进 `sw.js` 的 `SHELL` 列表。

登记两种以上语言后，「显示」面板里会出现语言选择。内置曲谱的正文和 `manifest.webmanifest` 的应用名是内容数据，不随语言变化。曲谱文本里的中文写法（如 `标题:`、`和弦:`）属于文件格式，也不随语言变化，定义在 `src/music/format/syntax.js`。

### 改保存的数据

所有状态是 localStorage 里的一个 JSON 文档，键名见 `config/app.json` 的 `storage.key`。

- 增加字段：把默认值写进 `config/app.json` 的 `defaults`，旧数据启动时会自动补上。

### 维护时注意

- 文件名、配置键、变量、函数、CSS 类和曲谱字段都用英文基础单词，不用拼音。
- 添加或删除源文件和曲谱文件后，同步 `sw.js` 的 `SHELL` 列表，否则离线时缺文件。测试会查出遗漏。
- 换吉他录音时，同时改 `config/app.json` 的 `audio.samples.recordings` 和 `sw.js` 里的音高列表。每个录音的音分误差用 `src/audio/pitch-detect.js` 的 `detectPitch` 测，播放时减掉。
- 内置曲谱只收公有领域的作品。还在版权期内的歌只写和弦和扫弦，不写旋律和歌词。
- PNG 图标由 `scripts/make-icons.py` 按脚本里的坐标绘制（需要 Pillow）。改图标图形时，同时改 `assets/icons/icon.svg` 和脚本里的坐标，再运行 `python scripts/make-icons.py`。
