# 六弦本

六弦本是给吉他初学者用的练习和演出工具。练习时，在电脑或手机上看六线谱和简谱，跟着节拍器和示范音弹。出门弹唱时，用演出模式看大字和弦和歌词。它是纯前端网页应用，可以添加到手机主屏幕，离线使用。

## 功能

- 曲谱：和弦、简谱、扫弦箭头、音符、六线谱和歌词上下对齐。六线谱、和弦、歌词可以在「显示」里单独开关。「简谱」一组有两个开关，默认都关闭：数字，以及音符（一排带符头的节奏符号，在六线谱上方）。扫弦箭头跟着六线谱显示。
- 符号说明：谱面上方列出这首谱当前显示的符号，如休止符、扫弦箭头和三连音，切换「显示」里的开关后跟着变。
- 弦线与标签：六线谱左右两侧各选一种标签：弦号（123456）、音名（EBGDAe）、TAB 或不显示，默认左侧显示弦号。弦线可以选统一细线或仿真粗细。
- 版本：内置曲谱默认打开简单版。练习曲的简单版只有 1、2 弦上的旋律和歌词，完整版加上和弦。有完整版的曲谱可以在曲谱页标题下方切换。每个版本有自己的速度、变调夹和循环。
- 分类：曲谱页用「指弹」「扫弦」切换。指弹下分练习、游戏、动漫：练习是《生日快乐》《小星星》这类儿歌；游戏收经典游戏的配乐，包括一组《塞尔达传说》；动漫收动画的主题曲，如《蜡笔小新》。游戏和动漫一次只弹一根弦，几乎全在 1 到 3 弦。扫弦下是只有和弦的歌曲，如 Perfect。搜索时两边一起找。
- 小节：谱面上的竖线是小节线。节拍器照拍号数拍，重音在每小节的第一拍。曲子从弱拍开始时，第一小节是不完整的弱起小节。
- 排版：曲谱可以指定每行放几个小节，内置曲谱一行大致是一句旋律。没有指定时，每个段落从新的一行开始。一行放不下时，从中间拆成两行。
- 播放：预备拍、节拍器、示范音和当前音符高亮。示范音用古典吉他的真实录音。速度可以调。
- 跟随：播放时页面跟着正在弹的那一小节滚动。手动滚动后页面停在原处，点「回到播放位置」重新跟随。
- 点一小节：停着时，点一小节会把播放起点移到这里，旁边出现小工具，可以从这里播放或循环。播放时，点一小节会立刻高亮它，数几拍预备再从它开始播，拍数在「练习设置」里选，默认 2 拍。从弱起小节开始时，预备拍之后再走几下节拍器，到它的拍才开始。设了循环时，从循环段之前开始会播到循环段再反复，从循环段之后开始会播到曲终。
- 循环：选几小节反复练。可以设成每循环一次自动加快几 BPM，到设定的最高速度为止。
- 变调夹与移调：调号和示范音跟着变调夹变。只有和弦的曲谱可以换指法调。选好「想唱的调」后，会列出难和弦最少的几种夹法。难和弦指横按或要按到 3 品以上的和弦。
- 演出模式：大字和弦加歌词，深色舞台配色，屏幕常亮，有翻屏按钮。可以按演出歌单一首接一首弹。
- 和弦库：指法图标出手指编号和根音。点一个和弦可以听声音、看其他按法。
- 换和弦练习：当前和弦最大，下一个和弦显示在旁边或下方，最后一拍提示换和弦。手机上，和弦组合、拍数和速度放在底部面板里。
- 一分钟挑战：数一分钟内能来回换几次和弦，每点一次 +1 弹出 Perfect，每组和弦保存最近的成绩。
- 节奏：细分有四分、八分、三连音、十六分，另有常用扫弦节奏型。点格子可以修改，下方自动生成节奏谱：五线谱上的斜线符头，切音画成 ×，上方标扫弦方向。歌曲开头的节奏型也用这种谱。
- 跟拍测试：跟着节拍器点击，显示每一下偏早还是偏晚。可以先校准设备的点击延迟。
- 工具：节拍器、调音器（用麦克风）、六根空弦的标准音。
- 写曲谱：用 alphaTex 或 ChordPro 写，边写边预览，错误提示带行号。
- 导入曲谱：把网上下载的 Guitar Pro、MusicXML、Capella 文件转成 alphaTex，存成自己的曲谱。

## 在电脑上运行

在项目目录运行（需要 Python 3）：

```bash
python -m http.server 5173
```

然后用浏览器打开 http://localhost:5173 。直接双击 `index.html` 打不开，因为浏览器不允许从 `file://` 加载 ES 模块。

## 在手机上使用

离线缓存、调音器和屏幕常亮只在 HTTPS 页面或 localhost 上可用，所以手机要通过 HTTPS 网站打开。用 GitHub Pages 发布：

1. 把仓库推送到 GitHub。
2. 打开仓库的 Settings → Pages。
3. Source 选 Deploy from a branch。
4. 分支选 `main`，目录选 `/ (root)`，保存。
5. 部署完成后，用手机打开 `https://<用户名>.github.io/<仓库名>/`。
6. 添加到主屏幕：
   - iPhone：在 Safari 里点「分享」，再点「添加到主屏幕」。
   - Android：在 Chrome 菜单里点「添加到主屏幕」或「安装应用」。

打开过一次以后，没有网络也能用。有网络时，页面先取最新版本。网络超过 2.5 秒没响应时，页面用缓存。

在家里临时试用时，也可以用局域网：

1. 让手机和电脑连同一个 Wi-Fi。
2. 在电脑上运行 `python -m http.server 5173 --bind 0.0.0.0`。
3. 在手机上打开 `http://<电脑的局域网 IP>:5173`。

这种方式是 HTTP，离线缓存、调音器和屏幕常亮都不可用。

## 数据保存

自己的曲谱、设置、工具页的选择、演出歌单和练习记录保存在当前浏览器的 localStorage 里。清除浏览器数据会删掉它们，换设备或换浏览器也看不到。

曲谱页的「导出备份」把曲谱、演出歌单和练习记录存成一个 JSON 文件。在另一台设备上，用「导入备份」恢复这个文件。设置、工具页的选择、选中的版本和每首曲谱的速度、变调夹、循环不在备份里。

## 曲谱写法

有六线谱的曲谱用 [alphaTex](https://alphatab.net/docs/alphatex/introduction)，这是 alphaTab 的文本格式。只有和弦的弹唱谱用 [ChordPro](https://www.chordpro.org/chordpro/) 的 grid 段。文本以 `{` 开头时按 ChordPro 读，否则按 alphaTex 读。两种格式都只支持下面列出的写法，其他写法报错。编辑器右上角的「写法说明」是这一节的简版。

### alphaTex

```text
\title "小星星"
\artist "法国民谣"
\tempo 90
\ts 4 4
\ks C
\systemsLayout (2 2)
\lyrics "一 闪 一 闪 亮 晶 晶
满 天 都 是 小 星 星"
\instructions "弹准以后打开简谱，边弹边唱唱名。"

\section "第一段" 3.5.4{ch "C"} 3.5 0.3 0.3 | 2.3{ch "F"} 2.3 0.3.2{ch "C"} |
3.4.4{ch "F"} 3.4 2.4{ch "C"} 2.4 | 0.4{ch "G"} 0.4 3.5.2{ch "C"}
```

开头的标签：

| 标签 | 含义 |
|------|------|
| `\title "…"` | 曲名 |
| `\artist "…"` | 作者 |
| `\tempo 90` | 每分钟拍数 |
| `\ts 3 4` | 拍号，支持 4/4、3/4、6/8 这类以 2、4、8 为分母的拍号 |
| `\ks G` | 调。小调写 `Aminor`，降号写 `Eb` |
| `\capo 2` | 变调夹品位 |
| `\systemsLayout (2 2 3)` | 页面上每行放几个小节。写到的小节之后，每个段落从新的一行开始 |
| `\lyrics "…"` | 歌词，见下文 |
| `\instructions "…"` | 练习说明。`{T}`、`{1}` 到 `{4}` 显示成彩色手指标记（T 拇指，1 食指，2 中指，3 无名指，4 小指），有标记时说明上方显示图例 |

之后是小节，`|` 是小节线：

- `\section "主歌"` 写在小节开头，开始一个段落。
- 曲子从弱拍开始时，第一小节开头写 `\ac`。这一小节的长度是它所有音的时值之和，节拍器靠它找到每小节的第一拍。《生日快乐》从 3/4 拍的第 3 拍开始，第一小节只有一拍。
- 除了弱起小节和最后一小节，每个小节要正好填满拍号，否则编辑器给出提醒。
- `//` 到行尾是注释，`/* … */` 是多行注释。

音符和属性：

| 写法 | 含义 |
|------|------|
| `3.5` | 品.弦：5 弦 3 品，1 弦是最细的弦 |
| `3.5.8` | 带时值的音。`1 2 4 8 16` 是全音符到十六分音符。时值一直有效，直到写下一个时值。开头是四分音符 |
| `:8` | 单独改时值 |
| `(0.1 1.2)` | 同时弹的几个音，时值写在括号后，如 `(0.1 1.2).4` |
| `x.4` | 4 弦闷音 |
| `r`、`r.2` | 休止 |
| `{d}` | 附点，时值乘 1.5，只对这个音有效 |
| `{tu 3}` | 三连音，3 个占原来 2 个的时间，每个音都要写 |
| `{ch "Am"}` | 从这个音开始的和弦 |

几个属性写在一个括号里，如 `{d ch "Am"}`。

歌词按顺序对到音符上，休止符不占歌词。空格和换行分开音节，所以汉字之间也要空格。两个连续的空格，或者换行后的一个空格，表示这个音不唱新字（拖腔）。英文单词里的 `-` 也分开音节，`-` 留在前一个音节上。`[…]` 是不显示的注释。这些规则和 alphaTab 一致。

### ChordPro

```text
{title: Perfect}
{artist: Ed Sheeran}
{key: G}
{capo: 1}
{tempo: 63}
{time: 4/4}
{meta: strum q D D D D}
{meta: instructions 弹熟后把每拍改成「下 下 上」三连音更像原曲。}

{start_of_grid: 主歌 1}
| G . . . | Em . . . | C . . . | D . . . |
| G . . . | Em . . . | C . . . | G . D . |
{end_of_grid}
```

- 开头的指令：`title`、`artist`、`key`、`capo`、`tempo`、`time`。
- `{meta: strum …}` 是弹唱的扫弦节奏型，正好一小节：`w h q e s` 是全音符到十六分音符，后面加 `.` 是附点，加 `3` 是三连音；`D` `U` `X` 是下扫、上扫、切音，`r` 是休止。
- `{meta: instructions …}` 是练习说明，手指标记同 alphaTex。
- 和弦写在 `{start_of_grid: 段落名}` 和 `{end_of_grid}` 之间。每行以 `|` 开头和结尾，`|` 分开小节。小节里每格占一拍，格数等于拍号的拍数；`.` 表示延续前一个和弦。grid 的一行在页面上占一行。
- `#` 开头的行是注释。

### 导入曲谱

曲谱页的「导入曲谱」读这些文件：

- Guitar Pro：`.gp` `.gp3` `.gp4` `.gp5` `.gpx` `.gp7`
- MusicXML：`.xml` `.musicxml` `.mxl`
- Capella：`.capx`
- alphaTex 和 ChordPro 文本：`.atex` `.alphatex` `.cho` `.chordpro` `.chopro` `.crd`，原样存下

前三种由 [alphaTab](https://alphatab.net/) 读取，再转成上面的 alphaTex 写法。文件有几条六弦音轨时，先选一条。导入的曲谱存成自己的曲谱，并打开编辑器。

上面的写法装不下的内容会被改写或去掉，每一类改动在曲谱开头写一行注释：

- 非标准调弦换算成标准调弦的品位，比空弦还低的音去掉
- 延音线后半的音、倚音、第二声部去掉
- 推弦、滑音、击勾弦、泛音、揉弦、颤音只留音高
- 反复记号不展开，只按写出的小节记一遍
- 中途变的拍号和速度统一成第一小节的
- 短于十六分音符、长于全音符、复附点和三连音以外的连音改成最接近的时值
- 认不出的和弦名、对不上音符的歌词去掉

alphaTab 放在 `assets/vendor/alphatab/`，只在第一次导入时加载。升级时改 `package.json` 里的版本，然后运行：

```bash
npm ci
```

```bash
node scripts/vendor-alphatab.mjs
```

### 内置曲谱

内置曲谱放在 `scores/<分类>/` 下，在 `scores/index.json` 里登记。登记项的 `level` 是难度标签；有简单版和完整版的曲谱，难度写在各个版本里。ChordPro 文件的登记项写 `"format": "cho"`，其他是 `.atex`。增删曲谱文件后，同步修改 `sw.js` 里的离线文件列表。`npm test` 用 alphaTab 和 chordsheetjs 读一遍所有内置曲谱，核对它们是合法的 alphaTex 和 ChordPro，并且和应用自己的解析结果一致。
