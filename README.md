吉他曲谱本用于在手机上阅读、编辑和练习六线谱。界面支持中文和英文，首次按浏览器语言选择，之后记住设置。

运行 `npm install`，再运行 `npm run dev`。点选弦与拍点后输入品位，可修改时值、休止和延音，并撤销或重做。练习支持调速、暂停、当前位置播放和小节循环。

`scores/` 保存 alphaTex 源谱和 SVG 谱面。可以按下面的方式组织文件：

```text
scores/
  入门/
    曲目甲.atex
    曲目甲.svg
    曲目乙/
      notes.atex
      preview.svg
  练习/
    曲目甲.atex
```

曲库按目录路径分组。含单个 `.atex` 和 SVG 的子目录作为歌曲文件夹，归入上一级分组。曲名优先使用 alphaTex 的 `\title`，其次使用歌曲文件夹名或文件名。

SVG 优先与同名 alphaTex 配对。同目录只有一个 `.atex` 和一个 `.svg` 时，可以使用不同文件名。多个文件时只匹配同名文件；未匹配的歌曲仍可打开。设置里的“原谱预览”显示配对 SVG，编辑后的谱面由页面实时绘制。

开发服务器会读取目录变化。发布版添加或移动源文件后需要重新构建。浏览器保存记录使用源文件相对路径区分歌曲，移动源文件会形成新的曲目。

编辑结果和显示偏好保存到当前浏览器。用“导出 alphaTex”保存单首曲谱，用“备份曲库”保存全部编辑。恢复备份会替换浏览器曲库。生产构建可添加到桌面，并在首次缓存后离线打开。

谱面默认隐藏音符上方的节奏符号。在设置中打开“显示节奏符号”，可显示时值符号。设置也可调整左右标签、谱面大小和弦间距。

运行 `npm test` 和 `npm run check:scores` 检查核心行为及递归曲谱往返。运行 `npm run build` 生成网站。开发服务器运行时，`npm run test:browser` 使用静音 Chrome 验证实际输入。格式范围见 [格式说明](docs/format.md)，验证边界见 [验收记录](docs/validation.md)。
